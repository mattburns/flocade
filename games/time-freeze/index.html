TIME FREEZE

Watch half a second of a disaster. Then time stops — shuffle things about, start the clock again, and hope you've fixed it.

HOW TIME FREEZE WORKS

1. Press START TIME. You get about half a second of the scene — watch carefully, because that's all the warning you get.

2. Time freezes. Everything stops dead in the air. The blue arrows show which way things were going and how fast.

3. Drag anything with a dashed ring round it. Only those things can be moved — you can't touch the rest.

4. Press UNFREEZE and time carries on from exactly where it stopped. Did you fix it?

Got it wrong? Press ↻ and watch the whole thing again. Nothing is random — the same scene plays out the same way every single time.
